This project contains two basic C programs developed to practice fundamental programming concepts such as pointers, strings, arrays, loops, and functions. It is suitable for beginners and freshers who are learning C programming.

📂 Programs Included
1. String Length Using Pointer (1.c)

This program calculates the length of a string entered by the user using a pointer. It traverses the string character by character and counts the characters without using the built-in strlen() function.

Concepts Used: Pointers, strings, character arrays, fgets(), and while loop.

2. Cube of 2D Array Elements (2.c)

This program accepts a square matrix from the user and calculates the cube of each element. It uses a separate function and pointer arithmetic to access and process the array elements.

Concepts Used: 2D arrays, pointers, functions, nested for loops, and arithmetic operations.

🛠️ Technologies Used
Language: C
Compiler: GCC
Code Editor: Visual Studio Code
🚀 How to Run

Compile and run the first program:

gcc 1.c -o program1
./program1


Compile and run the second program:

gcc 2.c -o program2
./program2


For Windows, run program1.exe or program2.exe in the terminal.

Understand pointers and pointer arithmetic.
Learn string handling and array traversal.
Practice loops and functions.
